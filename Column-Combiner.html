Column Combiner

Load a sheet, choose a column to group by, then choose the column(s) whose values should spread across separate columns for each group.

1 · Load data CSV / XLSX

2 · Group by column

Rows that share the same value in this column are collapsed into one output row.

3 · Combine columns

Ctrl/Cmd-click (or tap each, on mobile) to pick several — e.g. "register no" — so each group's values land side by side in "register no 1", "register no 2", "register no 3"…
